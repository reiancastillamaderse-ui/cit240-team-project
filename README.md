## Windows Setup
1. Install [Git for Windows](https://git-scm.com/download/win), which includes Git Bash.
2. Create a free [GitHub](https://github.com) account if you don't have one.
3. Open Git Bash and set your identity:
   ```bash
   git config --global user.name "Your Full Name"
   git config --global user.email "your-email@example.com"
   ```
4. Clone the shared repository:
   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```
5. Create your own branch before editing anything:
   ```bash
   git checkout -b feature/your-branch-name
   ```

## How to Open the Page
1. Open the project folder in File Explorer.
2. Double-click `index.html`, or right-click it and choose **Open with** > your browser (Chrome, Edge, or Firefox).

You can also run `start index.html` from Git Bash inside the project folder.
